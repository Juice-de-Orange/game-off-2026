# Asset-Anforderungen

Alle noch benötigten Assets. Wer beim Bauen eines Pakets ein Asset braucht, trägt es hier ein, legt den
Platzhalter unter dem finalen Pfad an (Regeln: `docs/ASSETS.md`) und baut weiter.
Max' Asset-Pipeline arbeitet diese Liste ab.

> **Vorläufiges Format.** Das endgültige Format wird mit Max' Asset-Pipeline abgestimmt und dann hier ersetzt.

## Status
`offen` → `in Arbeit` → `final` (Datei ersetzt, `.meta` unverändert)

## Vorlage
```
### <Dateiname>
- Pfad: Assets/_Project/<...>
- Typ: 3D-Modell / Textur / UI-Grafik / SFX / Musik / Voice / Schrift
- Paket: Pxx
- Angelegt von: <name>, <Datum>
- Status: offen
- Platzhalter: <wie der Platzhalter aussieht, z. B. "grauer ProBuilder-Würfel 2×1×0,6 m">
- Final: <wie es aussehen/klingen soll, Größe in m, Besonderheiten>
- Referenz: <Link/Bild, optional>
```
