# Terminal (P34) entwertet den Scanner – und soll Moral im Spiel spürbar sein?

## Kontext
Martin hat nach Welle 1 alle Mechaniken gegen den Tagesablauf prüfen lassen (`docs/MECHANICS.md`, Lücken). Zwei Funde betreffen
deinen Entwurf, deshalb fragen wir dich, bevor wir etwas ändern.

1. **Terminal (P34, jetzt gebaut):** Klick auf den CRT → jeder Name und jede ID auf den Papieren des Reisenden ist ein Knopf → Abgleich
   mit der Fahndungsliste und Einreiseakte. Stehen auf zwei Papieren verschiedene Namen, sieht man beide nebeneinander – das ist genau,
   wofür man den **Scanner** (P16, Kiosk ab Tag 6) kauft. Außerdem macht es die Fahndungsprüfung zu einem Klick, gratis ab Tag 1.
2. **Moral (P08/P12):** Schleuse −1, bei Unschuldigen −3 – wirkt nur auf den Schlusssatz des Endes. Während des Spiels merkt man sie nirgends.

## Frage
Terminal:
- A) Nur Name + ID **vom Pass** abfragen (Fahndung, Einreiseakte); Widersprüche zwischen Papieren zeigt weiter nur der Scanner. (Martins Favorit)
- B) Jede Abfrage kostet Zeit (einige Sekunden, die Schlange wird ungeduldig), alles bleibt sichtbar.
- C) So lassen, wie es ist.

Moral:
- D) Im Spiel spürbar machen (eigenes Paket: z. B. Gedanken am Bullauge, Albtraum-Zeile im Brief, Abendgäste reagieren).
- E) So lassen – Moral bleibt verstecktes Ende-Kriterium.

## Annahme bis zur Antwort
Terminal bleibt wie gebaut, Moral bleibt wie sie ist. Nichts blockiert.

## Antwort
**Max, 09.11.:** Terminal: **A**, nur Name und ID vom Pass abfragen (Fahndung, Einreiseakte); Widersprüche zwischen Papieren zeigt weiter nur der Scanner. Moral: **D**, im Spiel spürbar machen, als eigenes Paket.
