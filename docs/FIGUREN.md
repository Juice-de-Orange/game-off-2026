# Wiederkehrende Figuren – Ablaufplan

Entwurf (martin, 07.11.), Grundlage für P75 (System), P76 (Figuren-Inhalte) und P77 (Verwahrung). Es sind **12 Story-Tage** geplant,
damit genug Inhalt da ist. Gekürzt wird bei Bedarf von hinten: Abschlüsse rücken vor, Tag 9–12 fallen weg. Danach folgt die
Endlos-Schleife (P73), in der Figuren nur noch selten und nach Bedingung auftauchen.

## Grundregeln
- Pro Tag höchstens **3 Figuren-Begegnungen**, der Rest sind normale Reisende (P15).
- Jede Figur durchläuft **Einführung → Entscheidung → Folge → Abschluss** (3–4 Auftritte).
- Was „geholfen“, „verraten“, „beschlagnahmt“ oder „tot“ bedeutet, legt **jeder Auftritt im Skript** fest. Schleuse = tot, die Figur kommt nie wieder.
- Folgen kommen **frühestens am nächsten Tag**, damit der Spieler den Zusammenhang merkt.
- Jede Figur hängt an mindestens einem Ereignis: Sie **löst es aus** oder **redet darüber**.
- Ausgelöste Ereignisse laufen wie die festen: Pinnwand (MARKET-Zettel), Durchsage, Gerücht des Barkeepers am Vorabend, Lage der Station (P36).
- Fahndungen zu Figuren hängen als **Steckbrief mit Passfoto** an der Pinnwand und werden vom RuleEvaluator geprüft.
- Neue Figuren ab Tag 5 kommen **Stück für Stück** (Tag 5, 6, 8), damit die zweite Hälfte nicht repetitiv wird.

### Neue Figuren (ab Tag 5)
- **Tobin Rask:** Kommt mit einer Arbeitserlaubnis für die Docks, schimpft über Löhne und Kälte. Bei der Entscheidung (Tag 7) fehlt ihm
  ein Stempel. Durchgelassen = geholfen → er organisiert einen Streik → **„Dock strike“ am nächsten Tag** (weniger Ware, Lage der Station ↑).
  Abgewiesen = verraten → er wird abgeschoben, seine Kollegen erzählen es dir an Tag 10 vorwurfsvoll.
- **Nell Varga:** Will ihren Sohn besuchen, der im Gefängnis der Station sitzt – **es ist jemand, den du verhaftet hast** (Quill, falls
  verhaftet; sonst ein fester Reisender aus P15). Gibt dir einen Brief für ihn zur Verwahrung (P77). Weitergeben = geholfen, lesen/behalten
  oder abweisen = verraten. Macht Verhaftungen persönlich.
- **Pim Oddo:** Fröhlicher Händler mit Koffern voller Zeug, bietet dir Muster zur Verwahrung an (Clownsschuhe, Glücksbringer). Papiere
  meist knapp in Ordnung. Durchgelassen = geholfen → **„Oddo's caravan“ zwei Tage später** (LUXURY billiger, neue Waren beim Kiosk).
  Verhaftet/beschlagnahmt (P08) = seine Ware landet im Inventar, er kommt nie wieder.

Jede Änderung an Ereignissen und Geld braucht ein **neues Rebalancing** (Economy Report). Dass die Schmuggler-Razzia nicht mehr fest an
Tag 3 kommt, wird nach diesem Plan und den neuen Figuren gemacht (Martin, 07.11.).

## Was P75 dafür können muss
1. Auftritt an festem Tag mit festem Platz (Korr #1 an Tag 1) und Auftritt mit Bedingung (Mira an Tag 4 nur, wenn sie an Tag 2 da war).
2. Je nach Ausgang verschiedene Auftritte am selben Tag (Mira an Tag 4: Essen **oder** Fälschung).
3. Ein Ausgang setzt ein Ereignis für einen späteren Tag (Razzia morgen, Karawane in zwei Tagen) und eine Fahndung (Quills Rache an Tag 7).
4. Verwahrung mit Rückgabe-Tag (P77): Senn, Quill, Nell, Oddo.
5. Bedingungen über den Familienzustand (Senn bringt Medizin nur, wenn jemand krank ist) und über andere Figuren (Nells Sohn = wen du verhaftet hast).
6. Folgen ohne Begegnung: Durchsage, Brief-Zeile oder Paket an einem späteren Tag.

## Entschieden im Call (max + martin, 07.11.)
- Alle acht Figuren bleiben, 12 Story-Tage, gekürzt wird von hinten.
- **Shifter:** gibt sich an Tag 1–7 als Widerstandskämpfer aus und versucht, dich anzuwerben bzw. zu überreden, ihm zu helfen. An Tag 7
  kommt heraus, dass er ein **Spion** ist. Es gibt **eine Schlüsselentscheidung** (große Bitte, Tag noch festzulegen): Wer ihm dabei hilft,
  wird an Tag 7 durch die Luftschleuse geworfen → Ende „Airlocked“ (P12). Alle anderen Hilfen bleiben ohne diese Folge.
  Der Steckbrief „auf Sicht terminieren“ an Tag 3 bleibt als Test der Behörde.
- **Korr:** Tutorial an Tag 1 (#1), danach verdeckter Prüfer.
- **Nells Sohn**, wenn der Spieler niemanden verhaftet hat: ein fester Reisender aus P15 (Max).
- **Ab Tag 13** tauchen keine Figuren mehr auf, nur normale Reisende aus Pools (P73).
- **Schmuggler-Razzia** löst Quill aus (Verrat an Tag 3 → Tag 4), nicht mehr fest an Tag 3 → Rebalancing.
