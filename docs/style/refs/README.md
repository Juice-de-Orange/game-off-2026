Nur zur Orientierung (Moodboard) — nichts davon wird ins Spiel übernommen, keine Logos/Namen/Schriftzüge kopieren.
Präfix: `ai_` = Alien: Isolation (**Asset-Design**), `mw_` = Mouthwashing (**Grafik/Rendering, Figuren, UI**),
`real_` = echte Fotos mit freier Lizenz (**Grundriss, Proportionen, Funktion**).
